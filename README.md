# AI Capacity Conversion Canvas

A practical, vendor-neutral framework for turning AI productivity gains into measurable business capacity.

AI projects often report hours saved. That is useful, but incomplete. Time becomes business value only when an organization decides how the recovered capacity will be used and verifies that speed did not reduce quality, control, or customer outcomes.

This repository provides a simple way to connect an AI-enabled workflow with:

- a credible baseline;
- a named business owner;
- measurable operational improvement;
- an explicit destination for recovered capacity;
- quality, risk, and human-oversight controls; and
- an evidence-based decision to scale, redesign, or stop.

## How to use it

1. Select one recurring workflow with a clear unit of work, such as a case, order, claim, report, or incident.
2. Complete the capacity canvas with the people who perform and own the workflow.
3. Measure the current process before introducing AI.
4. Run a bounded pilot and collect the same measures again.
5. Separate technical performance, adoption, operational improvement, and business value.
6. Scale only when the evidence supports the intended outcome and the controls are adequate.

## Core principle

**Time saved is potential capacity. Value is created when that capacity produces an observable result.**

Examples include shorter customer wait times, more completed cases, reduced backlog, fewer errors, more selling time, or work that was previously postponed.

## What this framework does not do

It does not prescribe a model, cloud provider, software vendor, or architecture. It is not a substitute for security, privacy, legal, compliance, finance, or workforce review.
